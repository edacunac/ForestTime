# Changelog

## 5.4.1 - 2026-10-30

- Removed the overlap at the 15% terrain-slope boundary.
- Defined slope classes as flat (0% <= slope <= 15%), moderate (15% < slope <= 30%), and steep (slope > 30%).
- Updated Kotlin to 2.4.21 and KSP to 2.3.12.
- Preserved the ForestTime 5.4.0 study format and application identifier.
